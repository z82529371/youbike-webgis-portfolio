# 🚲 YouBike 2.0 即時都會出行導航 (YouBike Real-Time Commuter Mobility)

> 一個以市民生活用車為核心、專注於真實街頭「借車尋位、還車防撲空」的現代化即時都會公共自行車導航系統。  
> **預設以高雄市（亞灣、巨蛋、駁二）為主場**，並具備跨都會（高雄 ⇄ 台北）一鍵飛越的多城市架構。

## 🌟 專案亮點與面試核心價值

本專案跳脫傳統 GIS「單純打點」的思維，從**使用者真實日常通勤痛點**出發：

- **痛點一**：出門走到站點前才發現「無車可借」？
- **痛點二**：騎到商辦或捷運站目的地才發現「滿柱無法還車」，面臨逾時扣款？
- **痛點三**：高雄幅員遼闊，長途移動或跨生活圈如何搶先租到「YouBike 2.0E 智慧電輔車」？

針對上述真實情境，本系統提供了一體化的即時生活出行解決方案。

## 🚀 核心功能特色

### 1. 🚲 我要借車 ⇄ 🅿️ 我要還車（雙意圖專注模式）

- **一鍵情境切換**：頂部膠囊切換鈕讓介面在「借車」與「還車」之間動態反轉。
- **直覺色彩映射**：
  - 借車模式下：視覺全面聚焦**「可借車輛」**，0 台空站標紅警示，充足標綠。
  - 還車模式下：視覺全面反轉為**「可還空位」**，0 位滿站標紅警示，一眼看清目的地有沒有車位。

### 2. 🚨 智能救援 —— 備援替代站主動推薦

- 當市民選取的目標站點遭遇「0 車可借」或「0 位可還」時，系統透過球面幾何演算法，**自動推算周邊 800 公尺內步行可達、且車源充足的最近備援站**。
- 清晰顯示**直線距離（公尺）**、**預估步行時間（分鐘）**，並提供一鍵平滑跳轉，解決市民在站前撲空的焦慮。

### 3. ⚡ YouBike 2.0E 智慧電輔車即時追蹤（高雄在地專屬亮點）

- 針對高雄主力普及的 2.0E 智慧電輔車，系統自動解析官方即時明細。
- 在站點車況卡與搜尋結果中，獨立標記金色電輔徽章（如 `⚡ 2.0E 電輔車：4 台`），為長途與橋樑坡道通勤者提供關鍵決策資訊。

### 4. ⚓ 高雄首頁 ⇄ 台北首都（跨都會多城市擴充架構）

- **高雄主場**：預設進入直接定位高雄市中心（亞灣愛河灣、美麗島、漢神巨蛋），載入高雄 1,500+ 處站點與 38 個在地行政區。
- **雙城平滑飛越**：頂部一鍵切換台北市，鏡頭跨越全台平滑對焦，展現高擴展性的多都會架構。

### 5. 🔍 在地關鍵字模糊搜尋與定位

- 整合地標、路名與站點名稱模糊檢索（例如：輸入「美麗島」、「巨蛋」、「駁二」立即提供候選清單）。
- 「📍 我的位置」一鍵定位市民當前 GPS 座標，顯示專屬光暈光標並自動鎖定最近可用站點。

### 6. ⏱️ 60 秒即時輪詢同步

- 每 60 秒背景自動靜默獲取最新開放資料，搭配時鐘倒數與鮮度時戳。
- 提供手動「🔄 立即更新」按鈕，支援離線示範資料優雅降級，確保介面永不中斷白屏。

## 🛠️ 工程設計與架構原則

- **純函式空間運算**：空間距離（Haversine 演算法）、步行時間推估、模糊檢索與行政區外包矩形計算皆封裝於無副作用的純函式中。
- **嚴謹測試守護**：具備完備的單元測試（包含雙城市資料解析、電輔車解析、替代站演算法）。
- **無 Magic Numbers**：視角中心、城市經緯度、顏色階層均由常數配置模組統一管理。
- **輕量高效工作流**：採用 `pnpm` 套件管理，建構產物輕量俐落。

## 💻 本機開發與指令指南

### 1. 複製專案與安裝依賴

```bash
git clone https://github.com/z82529371/youbike-webgis-portfolio.git
cd youbike-webgis-portfolio
pnpm install
```

### 2. 啟動本機開發伺服器

```bash
pnpm dev
```

### 3. 執行單元測試

```bash
pnpm test
```

### 4. 生產環境打包與預覽

```bash
pnpm build
```

### 5. 一鍵發布至 GitHub Pages

```bash
pnpm run deploy
```
